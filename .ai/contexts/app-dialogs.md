# Renderer confirmations and messages

Use async `appConfirm({ title, message, confirmLabel, danger })` and `appAlert({ title, message })` from `public/app-dialogs.js`. Native `confirm`, `alert`, and `prompt` (bare or on `window`, `globalThis`, or `self`) are forbidden by ESLint throughout `public/**`. The property rule matches named objects and cannot express the nested `document.defaultView` receiver; that spelling is not covered.

The adapter uses `showChoiceDialog`. All choice dialogs share a FIFO queue, including existing checkbox dialogs, so a busy dialog never becomes a cancellation. Confirm resolves to a boolean; an alert offers OK. The topmost choice overlay owns Escape and Tab even when focus drifts outside it. Escape, the close button, and the backdrop dismiss the current dialog. Tab stays inside it. Enter on a button activates that button; on a checkbox or outside the overlay it does nothing. Enter on the container accepts a non-danger dialog, but does nothing for `danger: true`, which requires a focused button. Destructive confirmations and the live-elsewhere warning focus Cancel; continuation prompts focus Open session. A running scheduled task shows an OK-only alert and refuses resume. Closing returns focus to the connected opener. App navigation and tool shortcuts are suppressed while a choice overlay is open.

Every caller must await the decision before its side effect. The Changes and Touched discard paths are async, including close, back, row switch, toggle, and reload. `returnToPanelList()` returns a boolean for an immediate transition, or a promise when a discard decision is pending. The diff's Escape listener swallows the event only when the return has already succeeded; it leaves an unhandled or pending Escape available to other listeners.

Main-process Electron dialogs remain outside this renderer rule.

The quit/reload guard ACKs immediately, waits on `appDialogsIdle()`, recollects the current buffers and shows its Save/Discard/Cancel controls. It does not hold the choice queue while saving; a foreground message can therefore be dismissed without deadlock. Its unsaved guard focuses Save (Save all for multiple files), so Enter invokes the browser's button activation, traps Tab and Shift+Tab, cancels with Escape, and restores its connected opener. The beforeunload veto and main-process protocol are unchanged.
